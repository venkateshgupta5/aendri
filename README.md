# Operation: My Wifeey Deserves 100% Attention ❤️

A tiny, hand-made interactive love game. Single self-contained `index.html` — no build step.

- Add her photos & edit text in-app via the ⚙️ **Setup** button (saved privately on the device, nothing uploaded),
  or drop `1.jpg … 5.jpg` into `photos/`.
- All copy, quiz, captions and the final letter live in the `CONFIG` object at the top of `index.html`.
